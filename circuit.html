전체 시스템 결선도

AC 220V부터 LED와 서보까지, Vision-AI Gesture Tracking Lighting의 모든 부품 연결을 한 장에 표시한 통합 결선도. 색상으로 신호 종류를 구분하고, 각 연결선마다 핀 번호와 신호 이름을 라벨로 붙였어요.

📌 통합 결선 핵심 포인트
  • 전원 분리: 서보(5V SMPS)와 LED(12V SMPS)를 별도 SMPS로 분리. Pi의 5V 핀은 서보에 절대 사용 금지
  • I2C 풀업: PCA9685 모듈에 풀업 저항이 내장되어 있어 추가 부품 불필요
  • 공통 GND: 5V SMPS GND, 12V SMPS GND, Pi GND를 한 점에 모아야 PWM 신호 노이즈 방지
  • 전해 캐패시터 1000μF: PCA9685의 V+/GND 사이에 부착해서 서보 기동 전류 충격 흡수
№ 01 · PHASE 1

전원부 결선도

AC 220V 입력부터 두 개의 DC 전원 분기까지. 서보와 LED는 절대 같은 SMPS를 공유하지 않아요. 부하 간섭 방지를 위해 SMPS 두 대를 독립적으로 운영합니다.

측정 체크포인트 (Phase 1)
측정점위치기대값신호
①LRS-35-5 출력4.95V ~ 5.05V (무부하)5V
②LRS-50-12 출력11.9V ~ 12.1V (무부하)12V
⚠ AC 220V 작업 시 주의
  • 반드시 콘센트 뽑은 상태에서 결선. PG 압착 단자는 전용 압착기로 단단히 압착
  • SMPS의 L/N 단자에 220V 입력, +V/-V 단자에서 DC 출력
  • 두 SMPS의 GND(-V)는 Phase 4에서 한 점으로 모음 (공통 GND)
№ 02 · PHASE 2

서보 액추에이터 결선도

라즈베리파이 5의 I2C 핀(GPIO 2, GPIO 3)으로 PCA9685를 제어하고, PCA9685의 PWM 채널 0번과 1번에서 두 서보의 신호를 보내요. 서보 전원은 5V SMPS에서 V+로 직접 공급되고, Pi의 5V 핀은 사용하지 않아요.

📌 Phase 2 결선 주의점
  • PCA9685의 VCC와 V+는 완전히 다른 핀. VCC는 로직 전원(3.3V), V+는 서보 전원(5V)
  • 전해 캐패시터 극성 주의: V+에 (+), GND에 (−) 단자 연결. 반대로 끼우면 폭발 위험
  • I2C 주소 확인: 터미널에서 i2cdetect -y 1 명령으로 0x40 확인
  • 서보 케이블이 짐벌 회전 시 끊어지지 않게 30cm 연장 케이블 사용
№ 03 · PHASE 3

조명 모듈 결선도

10W 스팟 라인과 3W 무드 라인을 분리해서 표시. 10W는 MOSFET을 거쳐 PWM 디밍하고, 3W는 HAM3005 드라이버에 PWM 디밍 핀이 내장되어 있어 라즈베리파이에서 직접 연결해요. 모든 LED는 정전류 드라이버를 통과해야 안전합니다.

📌 Phase 3 조명 회로 핵심
  • LED 정전류 드라이버 필수: 12V를 LED에 직결하면 즉시 손상. 반드시 HAM2121/HAM3005를 거쳐야 함
  • 10W 라인은 2단 디밍 구조: Pi PWM → MOSFET 스위칭 → HAM2121 정전류 → LED. MOSFET이 거친 ON/OFF를 빠르게 반복
  • 3W 라인은 1단 직접 디밍: HAM3005에 PWM 입력 핀이 내장되어 있어 Pi에서 직접 연결
  • 방열은 절대 생략 금지: 써멀패드 → 방열판 → LED 순서로 부착. 점등 전 반드시 확인
№ 04 · PHASE 4

통합 + PIR 결선도

Phase 2와 3의 모든 회로에 PIR 모션 센서와 카메라를 추가한 통합 결선도. PIR은 GPIO 23에 인터럽트로 연결되어 Standby 모드에서 시스템을 깨우는 트리거 역할을 해요. 모든 GND는 한 점에 모아요.

📌 Phase 4 통합 체크리스트
  • 전원 인가 순서: ① Pi 부팅 → ② 5V SMPS ON → ③ 12V SMPS ON. 역순이면 서보가 갑자기 풀스윙할 수 있음
  • PIR 감도/딜레이 조정: HC-SR501의 두 가변저항으로 감도(SX)와 트리거 시간(TX) 캘리브레이션
  • 카메라와 짐벌 분리 마운트: 카메라가 짐벌과 함께 움직이면 좌표계가 흔들림. 거치대에 별도 고정
  • 인터럽트 등록: Python gpiozero.MotionSensor(23)로 콜백 등록하면 Standby에서 자동 복귀
