№ 01 · Build Plan

회로 빌드를
단계별로 짜기

비전 AI 알고리즘은 어느 정도 동작하고 있고, 이제 하드웨어 회로를 구현할 차례. 한 번에 다 연결하지 말고, 각 서브시스템을 따로 검증한 다음 차근차근 합쳐가는 게 핵심이에요.

!

전체 빌드 전략 — "작게 검증, 크게 통합"

회로를 한 번에 다 연결하면, 안 될 때 뭐가 문제인지 찾기 너무 힘들어요. 특히 LED 드라이버 + 서보 + 카메라가 한 보드에 다 붙으면 전원 노이즈 지옥이에요. 각 부품/서브시스템을 단독으로 검증한 다음, 검증된 모듈을 차례로 합치는 게 디버깅 시간을 10배는 줄여줍니다. 5월 1~2주차 통합 마감을 고려해 아래 4단계로 진행해요.

단계 개요

아래에서 위로 — Phase 1부터 차근차근.

1

전원부 검증

SMPS / AC 220V 입력 / DC 분기
약 0.5일
왜 먼저 하는가

전원이 흔들리면 위에 올라가는 모든 게 의심스러워져요

서보가 뚝뚝 끊기는 게 코드 문제인지 전압 강하인지 구분이 안 가거든요. 가장 아래 계층부터 검증하면 위층 디버깅이 쉬워져요.

할 일 순서
  1. SMPS LRS-35-5 (5V 7A) 단독 결선 → 멀티미터로 무부하 전압 측정 (4.95~5.05V 사이여야 OK)
  2. SMPS LRS-50-12 (12V 4.2A) 단독 결선 → 동일하게 측정
  3. AC 220V 입력측을 PG 압착 단자로 깔끔하게 마감 (전용 압착기 필수)
  4. 출력측에 DC 전원 잭 스크류 어댑터를 달아서 브레드보드 전원 레일로 분기
  5. 써멀패드를 미리 잘라두기 (Phase 3에서 LED 방열판에 붙일 거예요)
필요한 부품
SMPS LRS-35-5 SMPS LRS-50-12 파워 서플라이 케이블 PG 압착 단자 압착기 DC 잭 스크류 어댑터 써멀패드
AC 220V 작업은 반드시 콘센트 뽑은 상태에서 하세요. 의심스러우면 SMPS 두 개 다 12V/5V DC 어댑터로 임시 대체하고, 본격 검증은 나중에 해도 돼요.
2

액추에이터 모듈

PCA9685 / MG946R / MG90S / 팬-틸트 짐벌
약 1일
이 단계의 목표

라즈베리파이가 PCA9685를 통해 짐벌의 Pan/Tilt 모터를 원하는 각도로 보낼 수 있는지 확인

중간보고서의 Point 제스처 → 각도 변환 로직과 연결되는 부분이에요. 모터가 정확하게 각도를 따라가야 ER-01(2m 거리에서 30cm 오차 이내) 충족이 가능해요.

결선 구조
할 일 순서
  1. 팬/틸트 브라켓 키트에 MG946R(하단/Pan)과 MG90S(상단/Tilt) 조립. 나사 살짝만 조여놓고 각도 캘리브레이션 후 본격 체결
  2. PCA9685를 라즈베리파이 I2C 핀에 연결 (SDA → GPIO 2, SCL → GPIO 3)
  3. PCA9685의 V+ 단자에 5V SMPS 연결. 라즈베리파이의 5V 핀을 쓰면 절대 안 돼요 — MG946R 기동 전류가 1A 이상이라 파이가 리부팅됩니다
  4. 전해 캐패시터 1000μF를 PCA9685의 V+/GND 사이에 부착 → 모터 급기동 시 전압 강하 흡수
  5. Python 테스트 코드로 두 모터를 0°, 45°, 90°, 135°, 180° 차례로 보내보기
필요한 부품
PCA9685 (PWM 드라이버) 팬/틸트 브라켓 키트 MG946R MG90S × 2 점퍼 케이블 F/F 10cm 전해 캐패시터 1000μF 서보 연장 케이블 30cm 5V SMPS
검증 기준 (ER-01과 연결): 명령 각도와 실제 각도 오차 ±2° 이내, 짐벌이 부드럽게 회전하고 떨림 없음.
3

조명 모듈

10W 스팟 + 3W 무드 + MOSFET 디밍 + 방열
약 1.5일
왜 까다로운가

회로상 가장 신경 써야 하는 단계예요

고휘도 LED는 반드시 정전류 드라이버를 통해야 해요 (전압원에 직결하면 즉시 타버려요). 발열 관리도 중요해서 방열판 + 써멀패드가 필수예요. 10W 라인과 3W 라인을 따로 검증한 후 통합해요.

10W 스팟 조명 회로
할 일 순서
  1. 써멀패드 부착이 가장 먼저. LED를 방열판에 안 붙이고 점등하면 5초 안에 칩이 손상돼요. 3M 써멀패드를 LED 크기에 맞게 잘라서 LED 후면 ↔ 방열판 사이에 끼우고 단단히 압착
  2. 10W 라인 1세트만 먼저 테스트: 12V SMPS → HAM2121 정전류 드라이버 → 10W COB LED. 정상 점등 확인 후 집광렌즈 끼우기
  3. 3W 라인 1세트만 테스트: 동일하게 HAM3005 → 3W LED. 정전류 드라이버 출력이 안정적이면 8개 라인으로 확장
  4. MOSFET 디밍 추가: 라즈베리파이 PWM 신호를 HQ00933 모듈의 트리거 입력에 연결. 100Hz 이상 PWM으로 0~100% 밝기 스윕 테스트
    참고: HAM3005는 이미 PWM 디밍 핀이 내장되어 있어서 MOSFET 없이 바로 라즈베리파이 PWM 연결 가능. HQ00933은 10W LED에 더 적합
  5. 악어 클립 케이블로 임시 테스트 후, 검증되면 점퍼 케이블이나 압착 단자로 정식 결선
필요한 부품
SMPS LRS-50-12 MOSFET 모듈 HQ00933 LED 드라이버 HAM2121 LED 드라이버 HAM3005 10W COB LED 3W LED × 8 집광렌즈 15도 60mm 방열판 20mm 방열판 × 8 써멀패드 악어 클립 케이블
검증 기준 (ER-03과 연결): PWM 듀티 0~100% 변화에 따라 부드러운 디밍, LED 표면 온도 60°C 이하 유지 (장시간 점등 시).
LED 점등 시 절대 직시하지 마세요. 10W COB는 매우 밝아요. 흰 종이에 반사시켜서 광량 체크하세요.
4

통합 + PIR + 마운트

전체 결선 / 비전 파이프라인 / 거치대 조립
약 2일
통합 시 가장 중요한 두 가지

GND 일원화 + 신호선과 전력선 분리

1. 공통 그라운드: SMPS 5V, SMPS 12V, 라즈베리파이의 GND가 다 같은 GND를 공유해야 PWM 신호가 정상 전달돼요.
2. 케이블 분리: 점퍼 케이블(약전류)과 압착 단자 케이블(고전류)을 같은 다발로 묶지 마세요. 노이즈 들어가요.

할 일 순서
  1. PIR 모션 센서(HC-SR501)를 GPIO 인터럽트 핀에 연결 → 중간보고서의 Standby 상태 구현
  2. Phase 2 액추에이터 + Phase 3 조명을 하나의 브레드보드/PCA9685 보드에서 묶기
  3. 조명 거치대(삼각대)에 짐벌 + LED 모듈 마운트. 카메라는 짐벌 옆에 고정 (카메라가 짐벌과 같이 움직이면 좌표계가 흔들려요)
  4. 비전 파이프라인 연결: MediaPipe Point 제스처 → 3D 벡터 → Pan/Tilt 각도 변환 → PCA9685 → 짐벌
  5. 시스템 상태 전이 (Standby → Gesture Mode → Locked) 통합 테스트
  6. MR-01 검증: 2m 거리에서 포인팅 지점과 조명 도달점 오차 30cm 이내 측정
필요한 부품
PIR 모션 센서 조명 거치대 (삼각대) 브레드보드 카메라 어댑터 케이블 핀헤더 점퍼 케이블 (M/F)

일정 제안

주차 단계 산출물
이번 주 (5월 1주) Phase 1 + Phase 2 시작 전원부 OK, 짐벌 단독 동작
5월 2주 Phase 2 마무리 + Phase 3 짐벌 정확도 검증, 조명 디밍 동작
5월 3주 Phase 4 통합 전체 시연 가능 상태 + 최종보고서

마지막으로 권하는 안전 수칙

  1. 결선 전후 항상 사진 찍기 — 분해 후 재조립 시 헷갈림 방지 (부품 카탈로그 페이지 활용!)
  2. AC 220V 라인은 마지막에 연결 — 모든 DC 회로가 검증된 다음에 SMPS 220V 입력을 꽂으세요
  3. LED 첫 점등은 짧게(1~2초) 해서 연기/이상한 냄새 체크
  4. 압착 단자 사용 시 전용 압착기로 — 펜치로 누르면 접촉 저항이 커져서 발열의 원인이 돼요
